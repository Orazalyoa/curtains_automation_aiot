# Smart Curtains — система управления автоматическими шторами

Веб-приложение (HTML/CSS/JS, Chart.js, Firebase Firestore).

## Запуск
Открыть `index.html` в браузере. Без настройки Firebase данные сохраняются в `localStorage`.

## Подключение Firebase (облако)
1. https://console.firebase.google.com → создать проект.
2. Build → Firestore Database → Create database (режим *test mode*).
3. Project settings → Your apps → Web (`</>`) → скопировать `firebaseConfig`.
4. Вставить значения в `firebase-config.js`.
5. Обновить страницу — в шапке появится зелёная точка «Firebase подключён».

Коллекции в Firestore:
- `system/state` — текущее состояние штор, датчиков, настроек и расписания;
- `events` — журнал событий;
- `readings` — история показаний датчиков.

## Функции
- Управление 3 шторами: открыть / закрыть / любой процент, режим «Авто».
- Анимация движения штор (симуляция мотора).
- Виртуальные датчики: освещённость, температура, присутствие людей + авто-симуляция.
- Автоматизация: ночь → закрыть; жарко и никого нет → закрыть; яркое солнце → прикрыть.
- Расписание по времени.
- Предупреждения (яркое солнце, жара, холод).
- График показаний и статистика.
- История событий.

## Развёртывание
Firebase Hosting, Netlify или Vercel — просто загрузить папку проекта.
