Автоматизация

Работает для штор в режиме «Авто». Приоритет сверху вниз.

  1. Освещённость ниже лк → закрыть (ночь)
  2. Температура выше °C и никого нет → закрыть (энергосбережение)
  3. Освещённость выше лк → прикрыть до %
  4. Иначе → открыть полностью
